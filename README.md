## Selected Projects

### [cuAlign](https://github.com/hoddukzoa12/nvidia-hackaton-2026)

A team hackathon prototype for drafting and reviewing clear-aligner staging plans. It connects natural-language instructions, calculation tools, and 3D visualization so a dentist can inspect and revise a plan before exporting it.

**Python · NVIDIA NeMo Agent Toolkit · Nemotron NIM · Three.js**  
NVIDIA × FastCampus Korea Agentic AI Hackathon. Draft planning only; not a clinically validated treatment-planning system.

### [Property Tax Calculator](https://github.com/hoddukzoa12/incometax)

A map-based tool for estimating Korean property holding taxes. Users select an apartment, look up its assessed value, and compare yearly projections under stated tax assumptions.

**React · TypeScript · Cloudflare Workers · D1 · Kakao Maps**  
[Website](https://tax.rich-group.kr)

### [RichChat](https://github.com/hoddukzoa12/RichChat)

A shared inbox for a tax firm's customer inquiries, bringing messages, customer information, tasks, and documents into one workspace.

**React · TypeScript · Cloudflare Workers · D1 · Durable Objects**

### [IROS Property Lookup](https://github.com/hoddukzoa12/iros-property-lookup)

A tool for batch property-ID lookup and document preparation from address lists. It helps reduce repetitive searches and prepares spreadsheet forms for registry inquiries; login, payment, and official document access remain with the user.

**React · TypeScript · Cloudflare Workers · KV**
